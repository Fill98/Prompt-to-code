# Control Panel — Full Stack Project

Next.js frontend + Express backend + SQLite.

## Quick Start

```bash
# Terminal 1 — Backend
cd backend && npm install && npm run dev

# Terminal 2 — Frontend
cd frontend && npm install && npm run dev
```

Frontend: http://localhost:3000  
Backend: http://localhost:3001

## Features

- **Dashboard** — global toggles to disable buttons/inputs and hide tables across all subpages
- **3 Subpages** — each with 3 buttons, 2 text inputs, 1 data table
- **ERROR detection** — typing `ERROR` in any field turns buttons red + logs to SQLite DB
- **Animations** — page transitions, button click feedback, error pulse, input shake
